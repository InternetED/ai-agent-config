Requires the `grilling` skill installed alongside this one (do not install `grill-me` alone).

## Use when / Not for

- **Use when:** sharpening a plan, opinion, or claim with no working directory / docs trail.
- **Not for:** sessions that should leave ADRs or `CONTEXT.md` (use `grill-with-docs`); implementing or drafting deliverables.

Call the Skill tool with "grilling".

## Completion

Done when the claim/plan is sharpened enough that remaining disagreement is explicit, or the user stops the interview.
